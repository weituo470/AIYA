  - Download used: https://opengameart.org/sites/default/files/25-CC0-bang-sfx.zip
  - License: CC0 / public domain dedication.

- `achievement-celebration-fanfare.wav`, `achievement-celebration-chime.wav`
  - Source package: OpenGameArt, "Level up, power up, Coin get" / SoundPack01.zip
  - Download used: https://opengameart.org/sites/default/files/SoundPack01.zip
  - License: CC0 / public domain dedication as listed on OpenGameArt source page.
  - Conversion note: converted from AIFF to 16-bit PCM WAV for browser compatibility.
