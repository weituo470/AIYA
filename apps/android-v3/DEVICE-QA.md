# AIYA V3 真机验收清单

## 安装

```bash
pnpm --filter @aiya/android-v3 build
adb install -r apps/android-v3/app/build/outputs/apk/debug/app-debug.apk
```

## 主路径

- [ ] 启动后默认进入“创作”，没有登录、建档、声纹或新手引导弹窗。
- [ ] 软键盘“完成/回车”可直接提交文字需求。
- [ ] 按住语音按钮时才申请麦克风权限；松开后自动确认识别文本。
- [ ] 生成时可切换应用或进入后台，返回后任务仍能恢复。
- [ ] 生成成功自动进入“试玩”，作品画布不被顶部控件或 TabBar 遮挡。
- [ ] 同设备上的多个项目可切换、继续修改并回滚上一版本。
- [ ] “下载 HTML”“查看源码”“生成 APK”功能均有明确成功/失败反馈。
- [ ] 长按项目 3 秒才删除，普通点击不会误删。
- [ ] 检查更新失败时不会遮挡作品或造成循环重试。

## 体感与权限

- [ ] 前置摄像头只在作品请求视觉能力时弹出权限。
- [ ] 麦克风、相机被拒绝后，作品能显示可理解的说明。
- [ ] 人脸方向、手势、设备方向、陀螺仪和震动按设备能力降级。
- [ ] App 进入后台后停止录音和相机采集。

## 诊断

```bash
adb logcat -b crash -d > aiya-crash-before.txt
adb logcat | grep -i "AIYA\|AndroidRuntime"
```

提交问题时请附版本号、设备型号、复现步骤、诊断 ID 和脱敏后的日志。不要上传模型 Key、用户语音或真实个人数据。
